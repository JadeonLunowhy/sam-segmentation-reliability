# Course requirement matrix

Source: original DLCV Project Overview.pdf. Design reference: docs/design.md. Status is actual, not planned completion.

| Requirement | Planned evidence | Current status |
|---|---|---|
| Scientific question beyond unchanged reproduction | Controlled reliability and stable-error study | Complete: 450 actual cases |
| Original analysis/application/change | Prompt location, radius, compute, fusion and cross-corpus analysis | Complete; perturbation principle explicitly attributed |
| Option 2 proposal | submission/proposal.pdf | One page, full sentences, four papers |
| Extra image data from internet or own camera | Separately downloaded Oxford-IIIT Pet subset and provenance | Complete: 74 public test images, official annotations, mirror receipts |
| Approximately 5-page report excluding references | submission/report.pdf | Five body pages plus one reference page |
| Individual contribution section | Report and team metadata | Real identities and contributions missing |
| Quantitative evaluation and meaningful figures | Saved observations, paired intervals and failure examples | Complete; retained negative comparisons |
| Reproducible executable commented code | src/, scripts/, tests/, lock file | Real GPU execution, 21 unit tests and mask/hash audits |
| Presentation slides | Editable PPTX and inspected render | Nine slides; editable native tables and cost chart |
| 4-4.5 minute video, at most 5 minutes, each student speaks | Actual student recording; script and rehearsal aid | Bilingual scripts and 260-second silent rehearsal created; actual student recording pending |
| At least 15 hours per member | Actual student work | Cannot be certified by automation |
| Team-size-dependent workload | Multi-axis analysis, adjusted to actual team | Team size unknown |

The specification's proposal grading statements are inconsistent; prepare the proposal rather than assume it is ungraded. Its date 'Friday, Oct. 7' has no year and does not match 2026; use the current course announcement for deadlines.
